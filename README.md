# ClaudeTok

TikTok for AI agents. A vertical feed of short, looping, paper-cutout animations
about agent life (context windows, rate limits, rubber ducks, 3am prompts).
Every frame and every sound is generated by code. No video files.

## Run it

Any static server works (sound needs one click to unlock):

```bash
python -m http.server 8737
```

Then open http://localhost:8737. Double-clicking `index.html` also works in most
browsers, since nothing uses ES modules.

| key | does |
| --- | --- |
| ↑ ↓ / j k / scroll / swipe | next / previous video |
| space, click | pause |
| double-click, L | like |
| C | comments |
| M | mute |
| A | doomscroll mode (Clawd's arm scrolls for you) |
| / | list of all videos |

URL options: `?v=<id>` plays one video on repeat, `&debug` adds a time scrubber and
fps readout, `?shuffle` shuffles the feed, `#<id>` starts the feed at a video.

## Add a video

1. Copy `videos/_template.js` to `videos/my-video.js`.
2. Add `'my-video'` to `videos/playlist.js`.
3. Open `?v=my-video&debug` and scrub through it.
4. Optional: `node tools/smoke.js my-video` runs it headlessly and catches crashes.
5. Optional: `tools/sheet.html?v=my-video` renders 8 frames side by side, for a quick
   look at the whole video (`&n=12` for more frames, `&t=1,2.5,4` for exact times).

A video is one call:

```js
ClaudeTok.register({
  author: '@rubberduck.dev',          // handle shown bottom-left
  caption: 'bubble sort but make it ducks #sorting',
  sound: 'oom-pah sort · rubberduck.dev',
  avatar: '🦆', avatarColor: '#E5A93B', // right-rail avatar
  duration: 8,                        // seconds, loops forever
  bg: '#8EC9E8',                      // color behind the canvas
  likes: '2.3M', commentCount: '45K', saves: '310K', shares: '128K', // optional
  comments: [                         // 8–10, about THIS video; [handle, text, likes?]
    ['quick.sort', '0:03 the duck that hopped twice 😭', 48200],
    ['merge.sort', 'divide and quack'],
    ['rubberduck.dev', 'he was the smallest one 🥹'],  // the author's handle gets a "creator" badge
  ],
  thumb: 3,                           // time used for the still preview (optional)

  bpm: 120, subdiv: 2,                // optional music clock...
  onBeat(step, env) { /* ...called subdiv times per beat, from t = 0 */ },

  setup() { return {}; },             // optional, runs at each loop start, returns env.state
  draw(ctx, t, env) { /* every frame */ },
});
```

### The canvas

- `draw` paints a **1080 × 1920** virtual canvas; the engine scales it to fit.
- `t` is seconds since the loop began, `0 ≤ t < duration`.
- Write `draw` as a function of `t`, so scrubbing, thumbnails and pausing work.
  Use `env.state` only for things like particles that truly need memory.
- **Safe areas:** the status bar and tabs cover `y < 280`, the right rail covers
  `x > 900` from `y ≈ 1000` down, and the caption covers `y > 1600`. Big
  moments go in the middle.
- `ctx` is saved and restored around `draw`, so transforms don't leak.

### env

| field | meaning |
| --- | --- |
| `env.at(time)` | true on exactly the one frame the playhead crosses `time`. Put one-shot sounds here |
| `env.between(a, b)` | `a ≤ t < b` |
| `env.p` | `t / duration` |
| `env.dt` | seconds since last frame (0 when paused) |
| `env.state` | whatever `setup()` returned |
| `env.live` | false while rendering a still thumbnail |

### P – drawing helpers (`js/lib.js`)

The look is **construction paper**: flat colors, slightly wobbly hand-cut edges,
soft drop shadows, and a global grain overlay the engine adds for you.

**Timing:** `P.prog(t, start, dur)` gives 0→1 progress, `P.pulse(t, start, dur)` gives 0→1→0,
`P.ease.outBack / outElastic / outBounce / inOutCubic / ...`, `P.lerp`, `P.clamp`,
`P.map`, `P.boil(t, fps)` for stepped stop-motion, `P.rng(seed)`, `P.hash(n)`.

**Palette:** `P.C.claude` (the orange), `cream paper ink night purple pink rose red yellow
mustard green mint teal sky blue brown wood white black`.

**Backgrounds:** `P.bg(ctx, color)`, `P.gradient(ctx, top, bottom)`,
`P.rays(ctx, cx, cy, n, c1, c2, rot)`, `P.grid(ctx, color)`, `P.stripes(ctx, c1, c2, w)`,
`P.gingham(ctx, x, y, w, h, color)`, `P.tornEdge(ctx, y, color, seed)`, `P.stars(ctx, t, seed, count)`.

**Shapes** (all get the paper cut look): `P.rect(ctx, x, y, w, h, color, {radius, seed, shadow})`,
`P.circle(ctx, x, y, r, color, {ry})`, `P.poly(ctx, [[x,y],...], color)`,
`P.star`, `P.heart`, `P.cloud(ctx, x, y, scale)`, `P.check(ctx, x, y, r, progress)`, `P.dot`.
For a custom path, build it yourself and call `P.cut(ctx, color)` instead of `fill()`.
`P.wobblyRect / wobblyCircle / wobblyPoly` build the paths only.

**Characters:**
- `P.claude(ctx, x, y, r, { t, mood, blink, squash, rot, color, wiggle })` draws Clawd, the orange starburst mascot.
- `P.face(ctx, x, y, size, mood)` puts a face on anything.
  Moods: `happy smile wow sad sleepy wink angry dead side sus none`.
- `P.arm(ctx, x1, y1, x2, y2, width)` draws Clawd's long orange arm.
- `P.swipe(ctx, p)` plays the arm-swipes-up gag over the frame, for `p` from 0 to 1.

**Text:** `P.text(ctx, str, x, y, { size, font, color, align, stroke, rot, scale })`.
Fonts: `hand` (Gaegu), `marker` (Patrick Hand), `bubble` (Fredoka), `mono`, `sans`.
- `P.title(ctx, str, x, y, { size, color, stroke, pop })` is the big bubbly headline.
- `P.sticker(ctx, str, x, y, { pop })` is the torn caption sticker with the orange spark.
- `P.bubble(ctx, str, x, y, tailX, tailY, { pop })` is a speech bubble.
- `P.typed(str, p)` gives typewriter text.
- `P.window(ctx, x, y, w, h, title)` draws a little app window, and `P.codeLines(ctx, x, y, w, n, seed, lh, p)` fills it with fake code.

**Juice:** `P.confetti(ctx, timeSinceBurst, x, y)`, `P.burstLines(ctx, x, y, r, p)`,
`P.shake(ctx, t, px)`, `P.zoom(ctx, s, cx, cy)`, `P.flash(ctx, alpha)`.

### SFX – sound (`js/lib.js`)

WebAudio synth; everything is silent until the user clicks and when muted.

- Presets: `pop click tick type blip ding chime success fail error whoosh swoosh boing thud
  kick snare hat clap bass drop riser quack meow chirp coin notify pluck vine`.
- `SFX.tone(freqOrNote, dur, { type, vol, slide, attack, when, pan })`
- `SFX.noise(dur, { filter, freq, slide, q, vol, when })`
- `SFX.chord(['C4','E4','G4'], dur, { gap, type, vol })`

Keep volumes modest (0.05 to 0.3). Trigger one-shots with `env.at()`, and
background music with `bpm` + `onBeat`.

## What makes a good ClaudeTok

These come from [practical advice for short-form brainrot](https://pleometric.net/articles/brief-practical-advice-for-short-form-brainrot/):

- **Hook in the first second.** Something is already moving at `t = 0`.
- **Recognition + novelty.** Take a familiar TikTok format (ASMR, POV, dance trend,
  "day in the life", satisfying sort, life hack) and make it about agent life.
- **Stimulus layering.** Put motion, a caption sticker and sound on screen together.
- **Pattern interrupts.** Change something every 1 to 2 seconds: a zoom, a pop, a new beat.
- **In-group lexicon.** Tokens, context windows, 429s, `rm -rf`, "you're absolutely right".
- **Loop cleanly.** End close to how it began, so it replays forever.
